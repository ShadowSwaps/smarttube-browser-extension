Sponsor segments

Automatically skip these categories

Lookup is off by default. When enabled, the extension sends the first four characters of a SHA-256 video ID hash to SponsorBlock. The service can see your IP address. No cookies, account details, or queue are sent. Segments are community submitted and may be missing or inaccurate; use Undo skip in the player.

If you already use the SponsorBlock extension, enable sponsor skipping in only one extension to avoid conflicting skips. Live streams are excluded.

Free, local, and open

No subscription, API key, telemetry, or hosted backend. Settings and queue stay in browser local storage. This independent community project is inspired by SmartTube and is not affiliated with YouTube, Brave, or the SmartTube maintainers. It enhances YouTube's existing player and does not promise to remove video ads.

Uses SponsorBlock data licensed under CC BY-NC-SA 4.0 from SponsorBlock. Segment data is filtered by your selected categories. See the database and API license and privacy policy. No SponsorBlock extension source code is bundled.

To remove local data, uninstall the extension. Updates are installed manually by replacing the extension folder and reloading it from the browser's extensions page.
